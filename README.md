# Pad Encrypted Password Manager (PEPM)

A lightweight application to store your account information and passwords, with One Time Pad encryption.

Default Password: admin

## Features

- **Secured File**: One time pad encryption which is theoretically unbreakable without the key file
- **Random Password Generation**: When prompted for a password, it will generate a random one for you by default
- **Switch Between Password or Key Login**: Can login with a password or switch it to the key file login so you can move the key file around
- **Import & Export File**: Possible to transfer or combine password files when moving devices

## Version History

V1: First manager with argon2 encryption, mostly generated by ai

V2: New base manager with all basic functionality and no encryption

V3: Final version with otp encryption, import & exporting, authentication mode switching and etc, with fixes to important bugs
