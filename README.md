# Password-Manager
A lightweight application to store your account information and passwords, with OTP encryption.

V1: First manager addition with argon2 encryption, mostly helped by ai.

V2: Reworked manager to be a lighter vertion, but without any encryption as the new base & less of ai as a crutch.

V3: Optimized vertion with full implementation of OTP encryption and bare bone functionality

Default Password: admin
